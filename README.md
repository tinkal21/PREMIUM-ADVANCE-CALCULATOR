# 🧮 Premium Advanced Calculator

A multifunctional desktop calculator developed using **Python and Tkinter** with a modern dark-themed graphical interface.

## ✨ Features

- Basic Arithmetic Operations
- Scientific Calculations
- Trigonometric Functions (Sin, Cos, Tan)
- Square Root, Logarithm and Factorial
- Pi (π) and Euler's Number (e)
- Percentage Calculations
- Finance Calculator (EMI & Loan)
- GST Calculator
- Simple Interest Calculator
- Compound Interest Calculator
- CGST & SGST Calculator
- Calculation History
- Keyboard Support

## 🛠️ Technologies Used

- Python
- Tkinter
- Math Module

## ⚙️ Requirements

- Python 3.x
- Tkinter (included with most standard Python installations)

No external Python packages are required.

## ▶️ How to Run

1. Clone the repository:

   ```bash
   git clone YOUR_REPOSITORY_LINK
   ```

2. Open the project folder.

3. Run the Python file:

   ```bash
   python Professional_Advanced_Calculator_Fixed.py
   ```

## 🎯 Project Objective

The objective of this project is to develop an easy-to-use calculator that combines scientific, mathematical, and financial calculation tools in a single desktop application.
